# MoodSync

MoodSync is a Python program that recommends music based on a user's mood.

## Features
- Mood-based song recommendations
- Simple user input
- Personalized experience

## How it works
The user enters how they feel, and the program suggests songs that match that mood.

## Technologies
- Python
